# Privacy policy - ChrisMedicals Backup

Last updated: 17 November 2026.

The tool is used only by its owner, on the owner's own Google account.

It uses the Google Drive scope drive.file: it can see and manage only the files it creates itself, not any other file in the Drive.

Files are encrypted on the owner's own computers before they are uploaded; Google stores only encrypted data.

No data is shared with, sold to, or sent to any third party. No analytics, no advertising, no cookies.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The owner can remove the tool's access at any time at myaccount.google.com/permissions and delete its files from Drive.
